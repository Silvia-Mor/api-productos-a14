1. ##### Requisitos previos
    Para ejecutar la API de productos es necesario tener instalado Node.js y npm.

2. ##### Instalación 
    Una vez descargado o clonado el proyecto, hay que acceder a la carpeta api-productos-a14 desde terminal y ejecutar el siguiente comando para instalar las dependencias 'npm install'.

3. ##### Arranque de la aplicación
    Para iniciar la API, ejecutamos el siguiente comando desde la carpeta del proyecto 'npm start'.
    Si todo funciona correctamente, aparecerá un mensaje indicando que la API está disponible en http://localhost:3000.

4. ##### Comprobación del funcionamiento
    Para comprobar que la API funciona, podemos acceder a la siguiente dirección desde el navegador o utilizar REST Client en VSC.
    http://localhost:3000/api/productos
    La respuesta debe mostrar la lista de productos disponible.
